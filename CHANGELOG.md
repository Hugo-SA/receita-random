# Changelog

Todas as mudanças relevantes deste projeto são registradas aqui.
O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e o projeto adota [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0]

### Adicionado
- Página com botão **Receita Nova!!** que busca uma receita aleatória na API TheMealDB.
- Exibição de imagem, categoria, origem, tags, ingredientes, modo de preparo e vídeo (quando disponível).
- Painel de contato com links para GitHub e LinkedIn.
- Tratamento de erros na requisição com mensagem amigável.
- README, guia de contribuição e templates de issue e pull request.
